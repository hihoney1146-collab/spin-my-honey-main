# Coin flip sound attribution

Processed clips in this folder are derived from CC0 (public domain) recordings on [BigSoundBank](https://bigsoundbank.com/) by Pierre SIBANARCO:

- **Spin / flick source:** [Coin spinning on a table #1](https://bigsoundbank.com/coin-spinning-on-a-table-1-s2697.html) (sound #2697)
- **Landing / edge source:** [Coin in cup #1](https://bigsoundbank.com/sound-0339-piece-de-monnaie-dans-tasse-1.html) (sound #0339)

Regenerate trimmed WAV files with:

```bash
node scripts/process-coin-flip-sounds.mjs
```

Source files live in `_src/` (not shipped to production builds if excluded).
